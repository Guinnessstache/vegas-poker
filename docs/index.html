Under the hood

One small Node.js process runs everything that has to be trusted: the deck, the betting rules and the pot math. Browsers only ever receive what they're allowed to see. Video and audio skip the server entirely and flow directly between players over WebRTC.

  • Three.js
  • Socket.IO
  • WebRTC
  • Express
  • Web Audio
  • node:test

Get started

Deal yourself in

You'll need Node.js 18+.

git clone https://github.com/Guinnessstache/vegas-poker.git
cd vegas-poker
npm install
npm start

Open http://localhost:3000, pick a name and click Create table. Open a second tab to play against yourself.

Browsers only allow the camera and mic on HTTPS pages, so give friends an HTTPS link with a free tunnel:

# Windows: winget install --id Cloudflare.cloudflared
# macOS:   brew install cloudflared
cloudflared tunnel --url http://localhost:3000

Open the https://….trycloudflare.com link it prints, create a table, and hit Copy invite.

It's a single Node process with no database, so any host with WebSocket support works. The repo ships with a Render blueprint and a Dockerfile.

Deploy to Render 
docker build -t high-roller .
docker run -p 3000:3000 high-roller

Friends on strict mobile or office networks may need a TURN relay for video — set TURN_URL, TURN_USERNAME and TURN_CREDENTIAL.

FAQ

Questions at the rail

Is this real-money gambling?

No. Chips are play money that only exist for the length of a table. There's no payment, cash-out, or account system.

The game runs at 10 fps on a good graphics card.

Your browser is probably drawing 3D without the GPU. Turn on "Use graphics acceleration when available" in Chrome or Edge settings and restart the browser. The ⚙ menu in-game shows your fps and which GPU is being used.

A friend can't see or hear anyone.

Video is peer-to-peer. Most home networks connect fine with the built-in STUN servers; some mobile carriers and corporate networks need a TURN relay. Cloudflare Calls and Metered.ca both have free tiers.

Does it work on phones?

Yes — the table, HUD and camera adapt to small screens and the game picks medium graphics on mobile. A full 8-camera table is heavy on a phone's upload, though.

What inspired it?

The seated first-person table and casino atmosphere of the PS3-era High Stakes on the Vegas Strip: Poker Edition. All art here is original and generated in code.
